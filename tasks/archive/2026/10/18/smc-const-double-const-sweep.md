## BLUF

Apply the two independent `const` opportunities from the shared standard
(`github.com/billsix/runClaudeInContainer:tasks/reference/cpp-coding-standard.md`, "Initialize
everything; `const` by default") across smc's first-party `src/` (never `third_party/`): pointee-`const`
(`const T* p`) and top-level `const` (`T* const p`). The 2026-10-15 pass had already done broad
`const`-by-default, so the delta was mainly top-level `const` on never-reassigned locals. Compile-time
only, no behaviour change. Done against the green `-Werror` gate from the sibling task. Achieved:
68 files, gate still green under gcc + clang, smoke passes.

## What was done

- **Tool-driven, not by hand.** `clang-tidy -checks=-*,misc-const-correctness` over `smc/src`, with a
  compile DB generated by `bear` (added to the image for this). Measured first: **858 suggestions**.
- **First attempt with `run-clang-tidy -fix` corrupted shared headers** — `float const const const … s`.
  It computes every TU's fix against the original source then stacks the identical header insertion once
  per includer (~40× for a header in 40 TUs). Reverted, and re-applied **serially, one `.cpp` at a
  time** (harness `tasks/adhoc/smc-const-double-const-sweep/measure-const.sh fix`): fix-then-next means a
  shared header is already `const` when the next TU is analysed, so it is qualified exactly once.
- **Result: 68 files, +645/-617** — top-level `const` on never-reassigned locals plus pointee-`const`
  where safe.
- **8 over-eager fixes reverted by hand**, caught by the `-Werror` rebuild (the tool const'd a local
  that is then stored into a non-const target): `level_player.cpp` — four `cLevel_Exit const* level_exit`
  stored into a `void* Game_Action_ptr` → dropped the pointee-`const`; `mouse.cpp` — `cSprite const*
  new_object` pushed into a non-const `cSprite_List` → dropped the `const`. (Lesson: `misc-const-
  correctness` is not infallible; the `-Werror` build is the real check.)
