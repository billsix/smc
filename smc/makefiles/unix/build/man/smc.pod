=head1 NAME

smc - a super mario like jump 'n run game.

=head1 DESCRIPTION

Secret Maryo Chronicles is an Open Source two-dimensional platform game 
with a style designed similar to the classic sidescroller games.
which utilizes the platform independent libray, SDL and since Version 0.98 OpenGL.

The game includes an editor (hit F8). You can find
useful hints in the documentation provided with SMC.
You can see the website too :
    http://www.secretmaryo.org
