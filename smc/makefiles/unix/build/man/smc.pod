=head1 NAME

smc - a super mario like jump 'n run game.

=head1 DESCRIPTION

Secret Maryo Chronicles is a two-dimensional platform game which 
utilizes the platform independent library, SDL.
It's a jump 'n run game inspired by Super Mario games.

The game includes a level editor (hit F8). You can find
useful hints in the documentation provided with SMC.
You can see the website too :
    http://smclone.sf.net/
